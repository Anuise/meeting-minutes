## Agent skills

### Issue tracker

Issues 與 spec 以 markdown 檔存在 `.scratch/<feature-slug>/`。See `docs/agents/issue-tracker.md`.

### Triage labels

沿用五個預設角色名稱，記在每個 issue 檔的 `Status:` 行。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — 根目錄 `CONTEXT.md` + `docs/adr/`。See `docs/agents/domain.md`.

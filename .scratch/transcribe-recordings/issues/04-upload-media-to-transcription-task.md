# 04 — 上傳：Media → Transcription Task

**What to build:** Submit 現在會把 mp3 送上內網的 ASR Service，並在本地留下這份 Recording 對應到哪一個 Transcription Task 的記錄。使用者跑完看得到「已送出」的明確回報，ASR Service 那頭多出一個任務。再跑一次不會重送，佇列裡不會出現兩份一樣的任務。

上傳前先確認對方還有空間：mp3 超過單檔上限或剩餘空間不足就明確擋下、不送。服務位址沒設定時給一句講得出「要去設什麼」的錯誤，而不是一個連線逾時。

**這張票同時負責探明三件契約沒說死的事**，結果直接決定 05 怎麼寫，探明後寫回 spec 的 Further Notes。
